# Project Description:
This document provides a general description of the term project for the Evolutionary Computing (EC) course. The aim of the project is to allow students to explore and apply key EC techniques through the development of a practical application or empirical study.

# Topic Selection:
You should select a suitable topic that requires employing one or more EC algorithms, including, but not limited to: 
- Genetic Algorithms
- Evolutionary Strategies 
- Genetic Programming 
- Differential Evolution 
- Particle Swarm Optimization 
- Multi-objective Genetic Algorithms 
- ...... 

for any application area, such as (but not limited to): 

- Neuroevolution: Evolving the weights, topologies, or hyperparameters of neural networks (e.g., integrating with Graph Neural Networks or deep learning architectures). 
- Large Language Model (LLM) Optimization: Using evolutionary techniques for prompt optimization, fine-tuning data selection, or integrating LLMs as operators within evolutionary algorithms. 
- Feature Selection and Dimensionality Reduction: Applying EC algorithms to select optimal feature subsets in high-dimensional datasets (e.g., gene selection for medical classification or bioinformatics). 
- Combinatorial Optimization and Routing: Solving complex scheduling, packing, or routing challenges (e.g., the Traveling Salesperson Problem, Vehicle Routing Problem, or network design). 
- Reinforcement Learning Control: Evolving reward functions or optimizing policies for agents in dynamic environments. 
- Symbolic Regression: Automatically discovering mathematical equations and models to fit data without predefining the model structure. 
- Algorithm Control and Hyper-heuristics: Using techniques to dynamically manage and select mutation/crossover operators during the evolutionary search process. 
- Continuous Global Optimization: Benchmarking algorithms against standard complex mathematical functions to evaluate convergence and exploration capabilities. 
- ... 

Your selected topic must be discussed with and approved by the course lecturer before any work begins. Originality, relevance, and feasibility will be key factors in evaluating topic proposals. 

# Group Formation:
Projects may be conducted in groups of 3–5 students. 
- Collaboration should be well-organized and clearly documented. 
- The final report must include a section outlining each member’s specific contributions to the project. 

# Project Report Format:
Part of your work must be submitted in the format of an IEEE conference paper. The following sections must be included: 
- Abstract: Summarize the motivation, approach, and key findings of your project (typically 150–250 words). 
- Introduction: Present the background, problem statement, and objectives of your work. 
- Literature Review: Include a review of 6–10 key studies related to your selected topic. These should be sourced primarily through Google Scholar. Summarize each reference, explaining its relevance to your work. 
- Methodology: Describe the approach, models, algorithms, or systems you used or developed. 
- Experimental Work: Present and discuss numerical results. Use publicly available or benchmark datasets when possible. Where appropriate, compare your results with those from the studies reviewed in your literature section. 
- Conclusion and Discussion: Summarize your findings, reflect on the implications, and suggest possible improvements or future work. 
- AI Usage Statement: Briefly detail how generative AI tools (e.g., ChatGPT, Gemini, GitHub Copilot) were utilized during the project development. Specify the tools used, the scope of their application (e.g., conceptual brainstorming, code debugging, text drafting), and how your group verified the accuracy and validity of the AI-generated outputs. 
- Data Availability: Link to your datasets, and other sources if available. 
- References: Use proper citation format for all sources, ideally following IEEE style.
